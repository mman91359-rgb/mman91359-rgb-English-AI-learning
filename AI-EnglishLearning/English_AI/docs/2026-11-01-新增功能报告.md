## 1. 背景与目标

管理员端此前只有 P0 最小闭环，写作 Tab 是占位卡片；学习中心的词汇/语法入口与翻译/听力/写作三个入口视觉不一致。本次目标：

1. 把交接稿的管理员 7 页和写作模块迁移到现有 Vue3 + Tailwind M3 工程。
2. 管理员端接真实后端接口，写作端按契约做纯 mock/localStorage。
3. 统一学习中心五个入口的 8/4 结构与主色体系。
4. 修复本地非 5173 端口登录 403，保证可直接预览。

## 2. 交付内容

### 2.1 管理员端 7 页

| 路由 | 功能 |
|---|---|
| `/admin/overview` | 8 个 KPI、`exerciseDegraded` 横幅、3 个图表卡、最近操作/待审核题目 |
| `/admin/users` | URL 同步筛选、服务端分页、详情/启禁用/改角色/一次性临时密码 |
| `/admin/users/:id` | 基本信息、金币、能力画像、学习统计 |
| `/admin/questions` | 待审核/已通过/已驳回 Tab、通过/驳回/AI 出题、行展开、409 冲突提示 |
| `/admin/notices` | 筛选、新建/编辑抽屉、发布/下线/删除 |
| `/admin/activities` | 筛选、新建/编辑抽屉、发布/结束/删除 |
| `/admin/operation-logs` | 只读筛选、行展开 JSON、分页 |

管理员侧栏改为分组导航；`/admin/logs` 兼容重定向到 `/admin/operation-logs`；P1 不再显示“下一轮”。

### 2.2 写作 Mock 模块

- `/writing` → `/learning?tab=writing`
- `/writing/practice`：顶部奖杯进度条、768/400 两栏、答题纸、30 分钟倒计时、10 秒自动保存、草稿恢复、提交确认、四步评分
- `/writing/report`：`raw/15` 与 `weighted/106.5`、五维评分、逐句批改（含 PUNCTUATION）、亮点、范文、重写建议
- `/writing/history`：题型/级别/日期/分数区间筛选、收藏/错题过滤、得分趋势
- 评分通过 `WritingScoringService` 抽象；当前 `MockWritingScoringService` 按内容确定性返回三套 fixture
- 草稿/收藏/提交记录按用户 ID 写入 localStorage，不调用 `/exercise`、`/ai`

### 2.3 学习中心入口视觉统一

五个入口统一为 8/4 栅格（主卡 8 列 + 右侧 2 卡 + 底部 3 卡）：

| 入口 | 主色 |
|---|---|
| 词汇 | `primary` 紫 `#67558C` |
| 语法 | 新增 `info` 蓝 `#1A5FB4` |
| 翻译 | `secondary` 青 `#0C6780` |
| 听力 | `tertiary` 绿 `#006E20` |
| 写作 | `warning` 琥珀 `#B45309`（浅色模式提亮） |

同时删除语法入口的硬编码 `#cdf0fa`、`#0e4f63`、green/cyan 原生色；修正首次 `?tab=grammar` 深链时每日目标未按当前 tab 初始化的问题。

### 2.4 本地登录 403 修复

根因有两层：

1. 网关 CORS 默认只放行 `http://localhost:5173` / `http://127.0.0.1:5173`，而预览使用 5180。
2. 仓库同时存在被 git 跟踪的 `vite.config.js` 与 `vite.config.ts`，Vite 优先加载旧的 `.js`，导致对 `.ts` 的修改不生效。

修复：

- `frontend/vite.config.ts` 与 `frontend/vite.config.js` 同步增加 dev 插件：`/api` 请求进入代理前把 `Origin` 重写为 `http://localhost:5173`。
- 不修改后端 CORS、不需要重启网关；任何本地 Vite 端口都可登录。

## 6. 已知限制 / 后续建议

1. 管理员写操作（新建/发布/删除等）只验证了弹窗与接口调用路径，未在共享库实际落数据；上线前建议在测试库做一轮完整写入回归。
2. 写作仍为预览模式：评分是三套确定性 mock fixture，草稿/历史只写 localStorage；后续可替换为 `HttpWritingScoringService`。
3. 写作入口的“AI 问答”仍为提示占位，未接入真实 AI 服务。
4. 前端暂无单元测试框架；本次依赖 type-check、build、浏览器冒烟与手工验证。
5. `vite.config.js` 是 `vue-tsc` 从 `vite.config.ts` 生成的跟踪文件，必须与 `.ts` 同步；建议后续把 `tsconfig.node` 的 `outDir` 移出项目根目录并清理生成物，避免再次遮蔽 `.ts`。
6. 构建仍有 chunk 体积警告（既有问题，未在本轮拆分代码）。
7. 管理员用户详情中的 `heatmapData` 目前以 JSON 字符串展示，后续可做可视化。
