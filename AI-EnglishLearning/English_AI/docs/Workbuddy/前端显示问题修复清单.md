## 本次修复内容

| # | 问题 | 涉及文件 | 修复方式 |
|---|---|---|---|
| 1 | AI 助手暗色主题文字对比度失效（几乎不可见） | `frontend/src/components/AiSidebarContent.vue` | `.dark :deep()` 选择器因 Vue scoped 会给 `.dark` 追加 `[data-v-xxx]`、而 `dark` 类挂在 `<html>` 上永不命中；改为 `:global(html.dark) :deep()` |
| 2 | 管理端头像图片 404（缺 `/api` 前缀） | `frontend/src/components/admin/UserAvatar.vue`、`frontend/src/components/admin/AdminTopbar.vue` | 头像为后端相对路径，统一拼 `/api` 前缀（并做了 `startsWith('/api')` 防重复拼接），与普通页面一致 |
| 3 | 个人中心「翻译」分误显示阅读分（字段错配） | `frontend/src/views/ProfileView.vue`、`frontend/src/i18n/locales/zh-CN.ts`、`frontend/src/i18n/locales/en-US.ts` | `RadarData` 无 `translationScore` 字段；将「翻译」行改为「阅读」，显示 `readingScore`，变量 `speakingScore` 重命名 `readingScore`，新增 i18n key `moduleReading`（阅读/Reading） |
| 4 | 移动端底栏导航不随语言切换 | `frontend/src/components/BottomNavBar.vue` | `navItems` 由普通 `const` 改为 `computed`，语言切换即时更新（对齐 SideNavBar 的写法） |

## 关键改动细节

### 1. AiSidebarContent.vue（暗色文字）

```css
/* 修复前（永不命中） */
.dark :deep(.ai-paragraph) { color: #e5e7eb; }

/* 修复后 */
:global(html.dark) :deep(.ai-paragraph) { color: #e5e7eb; }
```

影响范围：仅暗色主题下 AI 回复的段落/列表/代码/加粗/斜体文字颜色，5 组规则。

### 2. 头像 404

- `UserAvatar.vue`：新增 `resolvedAvatarUrl` computed，`props.avatarUrl` 为相对路径时拼 `/api` 前缀，模板 `:src` 改用 `resolvedAvatarUrl`。
- `AdminTopbar.vue`：新增 `adminAvatarUrl` computed，逻辑同上。

### 3. 翻译分 → 阅读分

- `ProfileView.vue`：模板「翻译」行 `$t('dashboard.moduleTranslation')` → `$t('dashboard.moduleReading')`，`{{ speakingScore }}` → `{{ readingScore }}`；`speakingScore` 变量重命名为 `readingScore`，赋值 `radar.readingScore`。
- i18n：`zh-CN.ts` / `en-US.ts` 新增 `moduleReading: '阅读' / 'Reading'`。

### 4. 底栏 i18n

`BottomNavBar.vue` 的 `navItems` 改为 `computed(() => [...])`，并规范化 import 顺序（`computed` 从 vue 引入）。

## 遗留说明

- **问题 #3 的语义取舍**：按用户确认，本次采用「改显示 `readingScore` 并改名」的纯前端方案。若后端后续补充 `translationScore` 字段，需再调整此处的字段映射与 i18n。
- 其余中低优先级问题（i18n 硬编码、`text-body-xs` 未定义、首页整页跳转、`v-html` 未转义等）尚未处理，详见 `前端显示问题清单.md`。
