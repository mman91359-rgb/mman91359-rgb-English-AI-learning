## 1. 已确认的显示问题（按严重程度）

### 高优先级（直接影响用户可见效果）

1. **AI 助手暗色主题文字几乎不可见** ✅ 已修复（2026-11-07）
   - 位置：`components/AiSidebarContent.vue` 第 489-511 行
   - 机制：暗色覆盖写成 `.dark :deep(.ai-paragraph)`，Vue scoped 会把 `.dark` 编译成 `.dark[data-v-xxx]`，但 `dark` 类挂在 `<html>`（组件外、无 data-v），规则永不命中 → 正文仍为深灰 `#374151` 叠深色气泡。
   - 修复：已改为 `:global(html.dark) :deep(...)`。

2. **管理端头像图片 404（缺 `/api` 前缀）** ✅ 已修复（2026-11-07）
   - 位置：`components/admin/AdminTopbar.vue` 第 29 行、`components/admin/UserAvatar.vue` 第 2 行
   - 机制：`avatarUrl` 是后端相对路径，普通页已拼 `` `/api${url}` ``，这两处直接用原值绕过网关 → 破图。
   - 修复：两处均改为拼 `/api` 前缀（含 `startsWith('/api')` 防重复）。

3. **个人中心「翻译」分显示成「阅读」分（字段错配）** ✅ 已修复（2026-11-07）
   - 位置：`views/ProfileView.vue` 第 200-202 行（显示 `{{ speakingScore }}`）+ 第 436 行（`speakingScore = radar.readingScore`）
   - 机制：`RadarData`（`api/stats.ts`）无 `translationScore`/`speakingScore`，仅 `readingScore`。
   - 修复：采用用户确认方案——「翻译」行改为「阅读」，显示 `readingScore`，`speakingScore` 重命名 `readingScore`，i18n 新增 `moduleReading`。若后端后续补 `translationScore` 需再调整。

4. **移动端底栏导航不随语言切换** ✅ 已修复（2026-11-07）
   - 位置：`components/BottomNavBar.vue` 第 25 行
   - 机制：`navItems` 是普通 `const`，`t('nav.home')` 仅 setup 时求值一次。
   - 修复：已改为 `computed(() => [...])`（`SideNavBar` 已是正确对照）。

### 中优先级

5. **全局 `user-select:none` 导致正文无法复制**
   - 位置：`assets/main.css` 第 17-24 行
   - 修复：对展示性文本块加 `select-text`，或按组件粒度放开，而非全局禁用。

6. **大量硬编码中文未走 i18n（切英文不生效）**
   - 集中在：`VocabularyView.vue`、`AssessView.vue`、`ProfileView.vue`、`ErrorBookView.vue`、`StatsView.vue`（热力图标签/tooltip）、`HomeView.vue`。
   - 修复：接入 i18n key。

7. **未定义 Tailwind 类 `text-body-xs` / `font-body-xs`**
   - 位置：`components/AiSidebarContent.vue` 第 13、161 行
   - 机制：`tailwind.config.js` 只有 `body-lg/md/sm`，无 `body-xs` → 类不生成、静默失效。
   - 修复：改用 `body-sm`/`label-sm`，或配置补 `body-xs`。

8. **首页整页跳转闪白**
   - 位置：`views/HomeView.vue` 第 522-531 行，用 `window.location.href`。
   - 修复：改 `router.push`。

### 低优先级（特定数据才触发）

9. **造句/错题本「清洗选项字母」误替换孤立大写字母**
   - 位置：`GrammarQuizView.vue` 第 682 行、`ErrorBookView.vue` 第 580 行
   - 机制：`.replace(/\b[A-D]\b/g, ...)` 误伤句子中孤立 A/B/C/D；`correctIdx` 解析失败且 `correctText` 为空时删掉字母致题干残缺。

## 2. 可能出现的问题（潜在风险）

1. **管理后台移动端无导航入口** — `AdminSidebar.vue` `md:flex` 隐藏 + `AdminLayout` 无汉堡/底栏，手机访问 `/admin/*` 无法切页。
2. **ECharts 不自适应 + 初始化竞态** — `StatsView.vue` 只监听 `window.resize`（第 379-381 行）无 `ResizeObserver`；`watch(immediate)` 挂载前 `chartRef` 可能为 null 致图表永不渲染。
3. **Toast 窄屏溢出** — `ToastNotification.vue` 固定 `w-80` + `right-4`，屏宽 <344px 溢出。
4. **超长单词无断行保护** — `WritingAnswerSheet`、`HistoryView`、`VocabularyView`、`VocabQuizView` 缺 `break-words`。
5. **TranscriptPanel 空态回退不完整** — 原文与歌词都空时落入歌词分支渲染空容器。
6. **暗色下浅绿/浅色反馈无 dark 变体** — `HistoryView`、`PracticeView` 的 `bg-green-50/40` 等偏亮割裂。
7. **TopAppBar 通知弹窗关闭判定脆弱** — 依赖 `.top-20` 类名 + 硬编码中文 `aria-label="通知"`（第 169 行）。
8. **AudioPlayer 区间播毕不自动续播** — 到 `activeEnd` 强制 pause 并 emit ended，question 播完不续播 article。
9. **移动端听力测验步骤指示起始为第 2 步** — `ListeningQuizView.vue` 第 284 行 `(showResult || selectedAnswer ? 3 : 2)`。
