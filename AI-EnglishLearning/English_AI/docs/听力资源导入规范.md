# 听力资源导入规范

**适用**：exercise-service 听力模块（`module_type=4`）
**目标**：完整真题音频不预切，按题组时间区间播放；字幕只存数据库，源文件不进 `public`。

---

## 1. 目录

```
English_AI/
├── listening-source/                 # 原始资源，gitignore，不提交
│   └── cet6-2022-12-1/
│       ├── manifest.json             # 题组、时间区间、题目编号
│       ├── transcript.docx           # 带 [mm:ss.xx] 时间戳的听力原文
│       ├── questions.json            # 选项/答案/解析（可来自 JSON 或人工整理）
│       └── report.json               # 导入校验报告（生成）
├── frontend/public/audio/exams/      # 运行时音频，gitignore
│   └── listening-cet6-2022-12-1.mp3
└── exercise-service/src/main/resources/db/migration/
    └── V1.0.x__seed_listening_<exam>.sql
```

- 音频、LRC、docx、PDF 可能含版权，**不要提交公开仓库**。
- LRC 源文件不要放 `frontend/public`，否则可被直接下载；只把内容导入 `listening_audio.lrc_content`。

---

## 2. Manifest 字段

```json
{
  "schemaVersion": 1,
  "examId": "cet6-2022-12-1",
  "level": "CET6",
  "audio": {
    "fileName": "listening-cet6-2022-12-1.mp3",
    "publicUrl": "/audio/exams/listening-cet6-2022-12-1.mp3",
    "totalSeconds": 1635
  },
  "source": {
    "transcriptDocx": "transcript.docx",
    "questionsJson": "questions.json"
  },
  "groups": [
    {
      "groupKey": "cet6-2022-12-1-g01",
      "listeningType": "LONG_DIALOGUE",
      "articleStartSeconds": 33.0,
      "articleEndSeconds": 152.72,
      "questions": [
        {
          "number": 1,
          "questionStartSeconds": 157.84,
          "questionEndSeconds": 175.06,
          "difficultyLevel": 3
        }
      ]
    }
  ]
}
```

约定：
- `articleStart/End` 是文章/对话段；`questionStart/End` 是当前题目的问题段。
- 起点包含、终点不包含；`end` 留 0.2~0.5 秒尾部余量。
- 同组所有题目共享 `groupKey/listeningType/articleStart/articleEnd/audio_url/lrc_content/transcript`。
- 题号必须与 docx 中的 `N. What...` 一致。

---

## 3. 题型

| 值 | 含义 |
|---|---|
| `SHORT_DIALOGUE` | 短对话 |
| `LONG_DIALOGUE` | 长对话 |
| `PASSAGE` | 听力篇章 |
| `LECTURE` | 讲座/讲话/录音 |
| `NEWS` | 新闻报道 |
| `OTHER` | 其他/历史数据 |

---

## 4. 导入流程

1. 准备 `listening-source/<examId>/` 的 manifest、docx、questions.json。
2. 复制 MP3 到 `frontend/public/audio/exams/`。
3. 运行：
   ```bash
   node scripts/import-listening.mjs check --exam cet6-2022-12-1
   node scripts/import-listening.mjs build --exam cet6-2022-12-1
   ```
4. 预览 `docs/pending-migrations/V1.0.x__seed_listening_<exam>.sql`、目标库、影响行数。
   脚本默认写到 `docs/pending-migrations/`，**不要直接写进 `db/migration`**，否则服务重启时 Flyway 会在审批前自动执行。
5. 审批通过后，把待执行迁移复制到 `exercise-service/src/main/resources/db/migration/`；
   按 `docs/数据库迁移规范.md`：备份 → `scripts/flyway.sh exercise-service migrate` → `validate`。
6. 浏览器验收片段播放、字幕、提交后原文、错题本、雷达。

---

## 5. 校验清单

- [ ] 每组题数、题号与 docx 一致，题干非空。
- [ ] 4 个选项 A-D，答案在选项内，`answerMeta.confidence=high`。
- [ ] `articleStart < articleEnd`、`questionStart < questionEnd`、均在音频总时长内。
- [ ] `articleEnd <= 首题 questionStart`，题间区间有序、不重叠。
- [ ] 每组至少 1 行 LRC；文章段和题目段都能找到字幕。
- [ ] 同组 `audio_url/audio_total_seconds/audio_start_seconds/audio_end_seconds/group_key/listening_type/transcript/lrc_content` 完全一致。
- [ ] `external_key` 唯一；重复执行迁移不新增行。
- [ ] 作答前 API 不返回 `transcript/lrcContent/analysis/correctAnswer`。
- [ ] 解析能从对应片段推出，无歧义、不泄题。

---

## 6. LRC 规则

- 支持 `[mm:ss]`、`[mm:ss.xx]`、`[mm:ss.xxx]`，一行多时间戳、`[offset:]`。
- 数据库存**完整音频绝对时间**，不按片段归零；前端按区间过滤后再减起点显示。
- 双语行建议 `[mm:ss.xx]English｜中文`；`transcript` 保留英文+中文两行，便于静态阅读。
- 时间必须单调递增；文章行与 `N.` 题目行分开校验。

---

## 7. 版权

真题音频、PDF、docx、LRC 仅用于本地开发/答辩演示。公开仓库只提交脚本、manifest 示例和文档；部署时单独挂载授权素材或替换为开放内容。
